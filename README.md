# Accessibility Checker — Rachel Dsouza

A WCAG 2.0/2.1 AA accessibility analysis tool built with React + Vite. Paste any URL or HTML snippet and get an instant accessibility report powered by axe-core — the same engine used by Google Lighthouse and Deloitte.

## 🛠️ Built With

- **React 18** — component-based UI
- **Vite** — fast dev server and build tool
- **axe-core** — industry-standard accessibility engine
- **CSS Modules** — scoped, maintainable styling

## ✨ Features

- 🔗 Scan any live URL for accessibility violations
- </> Paste and analyse raw HTML snippets
- 📊 Visual score ring with 0–100 accessibility score
- 🔴 Issues grouped by severity — Critical, Serious, Moderate, Minor
- 💡 Expandable issue cards with fix suggestions and affected elements
- ♿ Checks against WCAG 2.0 A, WCAG 2.0 AA, and best practices

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Open http://localhost:5173
```
